# Best FreeElec To-Do — Demo Login (No Node)

This is a simple demo version with NO Node.js, NO npm, and NO Firebase.

## Login
For demo purposes, you can enter any username/email and any password to log in.
Register also works and is stored in the browser.

## Features
- Login / Register (demo)
- Logout
- Add tasks
- Complete / uncomplete
- Delete
- Filter
- Each username has its own task list in localStorage

## Run
Just open `index.html` in a browser.

Note: This is a demo login, not a secure real authentication system.
